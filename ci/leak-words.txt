# leak-words.txt -- one ripgrep pattern per line; ci/leak-test.sh fails the
# build when any file in the tree matches one. Lines starting "# " and blank
# lines are not patterns.
#
# Exempt paths: CHANGELOG.md (but for spend figures), this file and every
# .png's pixels (approved by the owner, whose compressed bytes match by
# chance); a .png's text chunks
# (tEXt, zTXt, iTXt) are searched. Nothing else: a build's papers
# under .claude/briefs/ are untracked and ignored, and a tracked file there is
# searched like any other.
#
# Two exact texts are allowed, in this case: the repository's own address,
# pushprove-max/Commandeck (with or without a closing .git), anywhere; and
# the owner's full name in LICENSE, NOTICE, .claude-plugin/plugin.json and
# .claude-plugin/marketplace.json only. ci/leak-test.sh takes them out of a
# matching line and matches the rest again.
# An allowed text counts only with an allowed neighbour on each side. Before
# it: the line's start, a space, a quote, ( < [ / or :. After it: the line's
# end, a space, a quote, ) > ] , ; or a full stop that ends the line or stands
# before a space. Anything else beside it (a longer name, a dotted suffix, a
# path after the address) fails. A line that is not UTF-8 gets no exception.
#
# Allowed on purpose (the owner's order of 2026-10-26): a build's unit name, an
# issue number (#123) and a commit hash. People's names, paths under a person's
# home (caught by the name), ruling ids and secrets stay banned.
#
# A spend figure is banned too, the changelog included, by two patterns in
# ci/leak-test.sh, not here: a dollar sum with cents, comma thousands or three
# or more digits anywhere; one or two digits in text (.md, .txt, .json, the
# changelog, a --text message), as in code they are a shell or awk field. The
# dashboard's test fixtures it names hold made-up figures, and only those
# figures are taken out of their lines. A code example in text is text: write a
# shell parameter there with braces (${1}, not a bare dollar and digit), and an
# amount in words (30 US dollars).
#
# Order: product name (any case; also covers the hostnames and the domain),
# owner names, seat nicknames, sister products, an API host, secret key shapes
# (Anthropic, AWS, GitHub tokens, a private key block), a seat the plugin does
# not ship (bracketed so this file does not match it), a ruling id of the
# source project's log (nobody else can look one up: say the reason in plain
# words; a test fixture uses a date before 2000).
