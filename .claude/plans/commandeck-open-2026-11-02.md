The guard list names 19 host guards and four script refusals; 13 have a plugin equivalent. Each block becomes a warning (exit 0 with the text as context) or a rewrite (the corrected command runs), the pattern the plugin's own hooks already use. - hooks/hooks.json (C5, changed): the 23 `"onFailure": "block"` keys go; timeouts stay. Reader: Claude Code. A hook that times out or crashes is a non-blocking error.

- `commandeck.unitsFrame` (C16, new, pass 1): the working mark's turn, 0-3, a plugin state atom (in memory, the mod's session state; no file). Writer: the motion clock's `turn` only (every 1 s, +1 mod 4); the poll never moves it. Reset to 0 at each session start and when the clock stops (no unit working; motion off never starts it). Readers: the band, pane and status views (frame 0 is the still mark). No retry: a turn that throws is dropped and the next second's turn writes again. Ordering: a turn in flight when a poll stops the clock can write one more frame after the reset; no unit is working then, so no view draws it, and the next start resets it. No migration: absent reads as 0.
- `spin` in hooks/units.tsx (C16, new, pass 1): the motion clock's handle, a module variable (no storage). Written by the poll: set when `motion` is on and a unit is working, cancelled and cleared when none is, and cancelled at each session start before the poll restarts; at most one clock runs.
